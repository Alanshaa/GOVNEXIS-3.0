Guided Troubleshooting for Common Audit Failures
Solutions for Network, DNS, and TLS Connection Warnings

SSRF Policy Block: Host resolves to private/loopback IP

Cause: The target domain resolves to an RFC 1918 address (10.x, 172.16-31.x, 192.168.x) or localhost.
Solution: External audits are strictly restricted to public routable IP addresses. For testing internal applications, use the isolated Local Demo Lab sandbox on 127.0.0.1:8765.

TLS Handshake Failure / Certificate Verification Error

Cause: The remote server has an expired, self-signed, or untrusted certificate chain.
Solution: GOVNEXIS never disables certificate verification. Verify that the target server presents a valid certificate issued by a public CA, or test against the local HTTP demo server.

Connection Timeout Exceeded

Cause: The target host dropped packets, blocked the User-Agent, or took longer than 5 seconds to complete TCP handshake.
Solution: Verify that the host is online and allows inbound HTTP/HTTPS traffic from your network without web application firewall drops.
